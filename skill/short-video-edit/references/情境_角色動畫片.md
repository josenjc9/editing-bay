# 角色動畫片（主角是畫出來的角色，要像活的、彼此互動）

- **鏡頭表多三欄（同框的每一鏡）**：看向誰／對誰反應／反應延遲（預設 0.3～0.6 秒）。左右翻轉就能改視線方向。
- **同框角色不准停著等**：一個角色在跑路線時，另一個同時做自己的動作。
- **節奏預設**：轉一圈 1.5 秒、單一姿勢停 ≤0.6 秒、換姿勢時彈一下（22px、0.12 秒）。**時間由動作決定，不拿動作去填前期定的秒數。**
- **使用者說「快一點」＝整段變短**，不是只改段內切點；回報寫改前／改後秒數。
- **情緒線不倒退**：排完寫一行（例：生氣→互抓→扭打→累倒→和好→笑），和好之後不再出現打架素材。
- **版面碰撞**：每個姿勢量 alpha 外框，算最寬姿勢不碰旁邊角色、不出畫面；格線圖切在格線內側 1px，切完查四邊。
- **音效**：一個情緒點一個聲音，不配腳步等連續音；音色預設可愛。
- **特效**：只在事件那一下出現、約 1 秒散。字卡加特效先交一張風格示意圖，批准才做整支。
- **不准空等**：交付前成片每 0.2 秒抽一格看，連續 >0.8 秒沒有新動作也沒有音效，就剪掉或補動作。
- 深色角色疊深色畫面要加白邊（貼紙感）。跑步移動速度變快時，跑步格的每格秒數要同比例變短，不然像滑行。
- **三層做法**：①底片：ffmpeg 疊去背 PNG 做角色動作 ②特效層：HTML 動畫，底片當 `<video>`，字卡與特效疊上，時間點全由段長表推算 ③音效。元素要夾在兩層之間時，前景角色另出透明 webm（`libvpx-vp9 -pix_fmt yuva420p`）疊上去。
- **成片後追改**：直接對定稿 mp4 用 ffmpeg 逐格 trim 加 concat，不必回頭重跑三層。三條地雷：①剪照片段先用換鏡偵測（`select='gt(scene,0.1)',showinfo`）抓實際邊界，不信鏡頭表 ②新做的段要轉 bt709 並標色彩屬性，不然拼接後色彩標記掉 ③剪掉的段落裡有音效尾巴，用 `acrossfade=d=0.04` 接。
- ffmpeg 濾鏡字串裡不能放 `#` 註解；腳本要 `set -o pipefail`，渲染後確認段落檔時間有更新。
