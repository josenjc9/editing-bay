# 剪輯語法與敘事

何時讀：任務是「電影感／預告片／混剪／大片」，或鏡頭表要寫 `cut_reason` 時。這是通用的電影剪輯知識整理。

## 前期先答 5 件事（寫進鏡頭表旁）
觀眾要知道什麼（每段新增哪則資訊）／要感覺什麼／要看哪裡（主體、視線）／何時揭露／何時離開（要不要留餘韻）。

## 每個切點問：現在切、晚一秒切、不切，哪個最有助觀眾？沒答案就刪那個切點。
鏡頭表每鏡（第一鏡除外）寫 `cut_reason`（一句：為什麼在這切、為什麼接這一鏡）。

## 語法字典（選一個、寫理由）
- `hard_cut`：資訊／視角／時間／情緒轉變已夠清楚時的預設。風險：空間跳接。
- `cut_on_action`：動作進行中換鏡。檢查動作相位、方向、速度接得上。
- `match_cut`：靠相似錨點（輪廓／位置／動作／構圖／聲音／概念）。**錨點要在前期就定**，寫進 `anchor`；不要硬湊。
- `jump_cut`：同畫面跳時間，要標「有意」，否則被當技術錯誤。
- `j_cut`／`l_cut`：下一場聲音先進／上一場聲音延續。是聲畫時序，不是轉場特效。
- `montage`：每一鏡都要在段落裡新增意義，不是堆片段。
- `b_roll`：只在主鏡頭缺資訊或單調時用；填 `narrative_need` 與 `new_information`。四種功能：evidence（呈現談到的實物）／orientation（建立空間）／continuity_patch（蓋必要的剪接跳躍，**不得蓋事實誤導**）／emotion_texture。「有空就放」禁止。
- `dissolve`／`whip`／`zoom`：要有具體理由；純裝飾就退回 hard_cut。全片轉場仍守「≤3 種」。

## 轉場決策
先 hard_cut → 需要強調時間／空間轉換才往下 → 有錨點用 match／cut_on_action／J-L → 沒錨點且劇情需要可見過渡才 dissolve。

## 鏡頭長度
不要每 1～2 秒硬切。順序問：看得出誰在哪做什麼？動作有開始／轉折／結果？字卡讀得完？反應要不要餘韻？多留一拍更清楚還是少一拍更有力？

## 視覺節奏與音樂節奏分開
先定敘事事件（動作、注意力、轉折、停頓），再把音樂拍點當**可選**對齊點，優先對樂句端點與留白；不為 BPM 縮短人物反應。關掉音樂預覽一次，故事要還看得懂。

## 例
看到玩具→伸手→抓空→停頓→轉頭看鏡頭：抓空後眼神還在變就別因拍點提早切；伸手→抓空跨景別時查左右手與動作相位；觀眾還不知玩具在哪就先給建立鏡頭。

## 字卡玩法菜單
做法：**每張字卡先寫它在片裡的功能（名字揭曉／時間流逝／收束金句…），再從下表挑一種跟功能掛勾的玩法；相鄰兩張不用同一種。** 預設的「下方字幕」「失焦對焦」只算保底，不算設計。素材庫名稱可用 `npx hyperframes catalog --query "<英文描述>" --json` 查。

| 功能 | 玩法（白話） | 備註 |
|---|---|---|
| 名字揭曉 | 墨暈凝成字、墨漫開染黑（SVG 模糊加門檻、`mix-blend-mode:difference` 自動反相） | 自做 |
| 名字揭曉 | 黑底粗明體大字一拍一字硬切加閃白 | 只是其中一種 |
| 名字揭曉 | 影像從字形裡透出（`svg-mask-reveal`、`texture-mask-text`） | 未實測 |
| 名字揭曉 | 粒子聚成字（`particle-text-dissolve`） | 未實測、吃效能 |
| 時間流逝 | 數字滾動、單位字閃白砸下（`count-up`、`number-wheel` 或自做） | |
| 對仗／鏡像句 | 字的 match cut：共同字不動、其餘字交叉換位 | 先找句子裡的共同字 |
| 關鍵字強調 | 手繪標記圈／底線（`marker-highlight`） | 未實測 |
| 景深 | 字躲在主體後面（`caption-parallax-layers`） | 要有去背主體 |
| 氣氛 | 超大淡字背後慢飄（`mk-emphasis-type`） | 未實測 |
| 轉場 | 暖光漏光（`organic-light-leak-overlay`）；閃白（`editorial-flash-overlay`） | |

溫情片不用：故障閃爍、駭客解碼、斜衝、強甩鏡。所有玩法仍守：只用使用者給的字、對比 ≥3、字不壓臉、全片一種字體。
