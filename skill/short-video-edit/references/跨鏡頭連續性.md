# 跨鏡頭連續性

何時讀：任何多鏡混剪、角色片、同場景多角度。純單鏡靜態圖卡可跳過。

## 只對有角色／系列的片建 Continuity 記錄；已有角色表就引用，不另造
外形特徵與比例、服裝道具、場景左右關係與攝影軸線、景別與鏡位高度、主光方向與色溫、動作起訖姿勢、主色與質感。

## 每個切點寫三格（鏡頭表 `anchor` 欄）
`out_anchor`（上一鏡結尾抓住什麼）／`in_anchor`（下一鏡開頭接什麼）／`match`（形狀、動作、位置、方向、概念、聲音哪一種）。沒有錨點就寫「無，靠情緒／資訊切換」，不要空著。

## 切點驗證：抽 t-2、t-1、t、t+1、t+2 影格逐張看
工具：`tools/cuts_sheet.py 成片.mp4 輸出.png --times 切點秒數...`。**圖要逐張看**；沒看過的項目標 `unverified`，不寫 pass。

| 查什麼 | 典型失敗 | 修法 |
|---|---|---|
| 方向（screen direction） | 走出右側、下一鏡無交代走向左 | 換鏡位或補建立鏡頭 |
| 視線 | 眼神對不到另一角色／物件 | 修視線或換序 |
| 動作相位 | 還沒伸手就出現抓到 | 調入出點或補中間 |
| 景別突變 | 無故縮放 | 改構圖或設計成明確景別轉換 |
| 空間關係 | 物件左右互換 | 補建立鏡頭 |
| 身份 | 毛色、比例、道具跳變 | 局部修，必要才重生單鏡 |
| 光線 | 同場景影子反向 | 調光色或換鏡 |
| 時間 | 接切動作重播、跳格 | 調切點與時基 |

180 度軸線不是鐵律，有意圖的越軸可以；準則是觀眾看不看得清楚。景別、方向、光線可以因敘事有意改變，看設計意圖，不是每個差異都算錯。

## 修正順序（最小變更）
移動切點 → 換序／換備用素材 → 局部變速 → 局部遮罩合成 → 重渲單鏡 → 重生指定資產。不改已核准的角色參考圖與身份特徵，除非使用者同意。
