# 轉場指南

何時讀：鏡頭表要決定「這一刀怎麼接」、或要實作轉場時。分三層：先決定**該不該轉場**，再選**哪一類**，最後才是**怎麼做出來**。

狀態標示：**實測**＝作者做在成片上過，或在寫這份時實際跑過；**列出但未逐一看效果**＝工具支援、作者沒逐一試；**依官方文件**＝整理自 HyperFrames 的公開文件。第一次用先做 5 秒測試。

## 一、先問：需要轉場嗎？

1. 預設硬切。資訊、視角、時間、情緒已經換了，硬切就夠。
2. 要強調「時間或空間換了」才往下。
3. 有錨點（相似形狀、動作、聲音）→ match cut、動作切、J／L cut（見 `剪輯語法與敘事.md`）。
4. 沒錨點、劇情需要看得見的過渡 → 才用溶接或特效轉場。
5. **全片轉場 ≤3 種**（動態圖形可到 3～5 種，每種都要由畫面上的東西引起）；硬切之外，場景接縫的硬切不超過約三分之一；兩個不同世界不要直接交叉淡化。
6. 純裝飾的轉場退回硬切。

## 二、選哪一類

| 想表達 | 用這類 | 備註 |
|---|---|---|
| 一般換鏡，不想被注意 | 硬切 | 場景內用推近（punch-in）讓同機位跳接不突兀 |
| 時間流逝、回憶 | 溶接（dissolve）、淡入淡出 | 短一點（0.3～0.6 秒），長了像 PPT |
| 場景結束、章節轉換 | 淡到黑（fadeblack）、淡到白（fadewhite） | 淡到白偏明亮、夢境；淡到黑偏收束 |
| 方向感、行進 | 滑動（slide）、推（cover／reveal）、甩鏡 | 方向要和畫面動勢一致 |
| 節奏型混剪、預告片 | 甩鏡、閃白、暗角切 | 配合音效重拍 |
| 有主體物的轉場 | 物件變成世界、穿過按鈕、從點擊處開圈 | 見 `動態圖形與3D.md` 第三節 |
| 溫情片、醫療場景 | 溶接、淡入淡出 | **不用**甩鏡、斜衝、故障閃爍、焦距衝擊 |

## 三、用 ffmpeg 做轉場（`xfade`）

這台寫作時用的 ffmpeg 支援下列轉場（用 `ffmpeg -h filter=xfade` 可查自己版本的清單）：

- **淡入類**：`fade`、`fadeblack`、`fadewhite`、`fadegrays`、`fadefast`、`fadeslow`、`dissolve`
- **擦除（wipe）**：`wipeleft`、`wiperight`、`wipeup`、`wipedown`、`wipetl`、`wipetr`、`wipebl`、`wipebr`
- **滑動（slide）**：`slideleft`、`slideright`、`slideup`、`slidedown`
- **平滑（smooth）**：`smoothleft`、`smoothright`、`smoothup`、`smoothdown`
- **推蓋與揭開**：`coverleft`、`coverright`、`coverup`、`coverdown`、`revealleft`、`revealright`、`revealup`、`revealdown`
- **形狀開合**：`circlecrop`、`rectcrop`、`circleopen`、`circleclose`、`vertopen`、`vertclose`、`horzopen`、`horzclose`、`radial`
- **對角**：`diagtl`、`diagtr`、`diagbl`、`diagbr`
- **切片與風**：`hlslice`、`hrslice`、`vuslice`、`vdslice`、`hlwind`、`hrwind`、`vuwind`、`vdwind`
- **其他**：`pixelize`、`hblur`、`distance`、`squeezeh`、`squeezev`、`zoomin`

**實測**：`smoothleft`、`fade`（成片用過）；`xfade=transition=smoothleft` 在這次寫作時用兩段合成影片實際跑過，輸出長度正確。其餘名稱「列出但未逐一看效果」。已知：**主體是黑色時別用 `zoomin`**（會放大到全黑），改 `smoothleft` 或 `fade`。

### 基本用法
```bash
ffmpeg -i a.mp4 -i b.mp4 -filter_complex \
  "[0][1]xfade=transition=smoothleft:duration=0.5:offset=1.5,format=yuv420p" out.mp4
```
- `duration`：轉場長度（秒）。
- `offset`：轉場**開始**的時間，通常等於「第一段長度 − duration」。
- 輸出總長＝兩段長度相加再扣掉 `duration`（2 秒＋2 秒、轉場 0.5 秒 → 3.5 秒，已實測）。
- 兩段的**解析度、fps、像素格式、time base 要一致**，否則報錯；先各自 `scale`、`fps`、`format` 一致化。

### 串多段
`offset` 是從第一段開頭起算的累積時間，不是每段各自的時間：每接一段，offset＝目前累積總長 − duration。段數多時用腳本算，不要手算。

### 聲音要另外接
`xfade` 只處理畫面。聲音用 `acrossfade`（長度與 `duration` 對齊），配樂接點用等功率交叉淡化（`afade curve=qsin`），避免先淡出再淡入的凹洞。

### 注意
- 轉場長度跟著敘事走：快節奏 0.15～0.3 秒，溶接 0.3～0.6 秒；更長要有理由。
- 轉場期間兩段都在動，素材結尾與開頭要留足餘量（handle），不要吃到動作的關鍵瞬間。
- 色彩標記不一致的段落（例如 SDR 與 HDR）接在一起會跳色；先統一到 bt709。

## 四、用 HTML 動畫做轉場（字卡與特效層）

- 素材庫有現成的轉場元件（甩鏡、漏光、縮放穿越、閃白、模糊交換等）。查法：`npx hyperframes catalog --tag transition --json`，或 `--query "<英文描述>"`。（依官方文件）
- 自己做的數值起點（9 種有原因的轉場）在 `動態圖形與3D.md` 第三節：穿過按鈕、物件變成世界、變形、帶著結果穿越、整片換色、甩鏡、從點擊處開圈、暗角切、同一舞台模糊交換。
- **換鏡前後各抽一格驗證**：隱藏狀態、元素殘留、疊影，只有逐格看得出來。
- 逐格渲染時，動畫要由時間決定（見 `動態圖形與3D.md` 第一節），否則轉場會在渲染時跳格。

## 五、交片前檢查（接到階段四）

- 轉場種類 ≤3（或動態圖形有理由的 3～5）？
- 每個轉場都能說出「為什麼用它」？說不出就改硬切。
- 切點前後各 2 格逐張看過（`tools/cuts_sheet.py`），方向、視線、動作相位接得上？
- 溫情、紀實素材沒有用強烈特效轉場？
- 聲音的轉場有接（沒有畫面轉了聲音硬切）？
