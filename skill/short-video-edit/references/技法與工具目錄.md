# 技法與工具目錄

何時讀：關卡 2 做「技法選型」時、製作階段想不到怎麼做時。每一項都標了狀態：

- **實測**：作者實際用在成片上過。
- **常見做法**：業界通用、ffmpeg 或工具官方文件有的用法，這份整理沒有逐項實跑；**第一次用先做 5 秒測試**，不要直接向使用者保證效果。

給使用者看的清單用白話名稱；英文濾鏡名只放內部對照。

## 一、剪輯技法（敘事層）

| 技法（白話） | 什麼時候用 | 注意 |
|---|---|---|
| 硬切 | 預設。資訊、視角、時間、情緒已經換了 | 空間跳接要補建立鏡頭 |
| 動作切（cut on action） | 動作進行到一半換鏡 | 動作相位、方向、速度要接得上 |
| 相似物切換（match cut） | 前後鏡有相似形狀、位置、動作、概念 | 錨點在前期定，不要硬湊 |
| 視線銜接／反應鏡頭 | 人物看→看到的東西→人物反應 | 可取代情緒類字卡；真實紀錄素材不可拼接不同時間的反應造假 |
| 對比與並置 | 兩鏡並排產生新意義 | 效果有爭議，只當可 A/B 的選項 |
| 聲音先入／延續（J cut／L cut） | 場景轉換更順 | 是聲畫時序，不是特效 |
| 跳接（jump cut） | 口播剪氣口、有意的時間跳躍 | 要標「有意」，否則像技術錯誤 |
| 蒙太奇 | 時間流逝、成長、多段濃縮 | 每一鏡都要新增意義 |
| 定格加變速 | 強調一個瞬間 | 變速鏡頭的聲音不要跟著拉伸 |
| 景別切換 | 每段中→近→遠 或 遠→中→特 | 同景別連切會平 |

完整語法與決策順序見 `剪輯語法與敘事.md`。

## 二、畫面與動畫技法

| 技法 | 做法 | 狀態 |
|---|---|---|
| 推進／拉出鏡頭 | ffmpeg `zoompan`，或 HTML 動畫對影片做 `scale` | 常見做法 |
| 轉場 | ffmpeg `xfade`（fade、wipe、slide、smooth、circle 等類型；要設 `duration` 與 `offset`） | 常見做法；實測用過 `smoothleft`、`fade`，主體是黑色時避免 `zoomin` |
| 調色 | `eq`、`curves`、`colorbalance`；S 型曲線＋黑位微抬＋暗角（`vignette`）＋顆粒（`noise`） | 實測（分離色調只上彩色段；不要用 colorbalance 亮部） |
| HDR／HLG 轉 SDR | `zscale` 線性化 → `tonemap=hable` → 轉 bt709 | 實測（npl=100 保得住投影幕細節） |
| 變速 | 畫面 `setpts`，聲音 `atempo`（單次 0.5～2.0，更大要串接） | 常見做法 |
| 字幕燒入 | 先把字畫成透明 PNG 再 `overlay`（相容性最好）；或 `subtitles` 濾鏡 | 實測 PNG 疊法；`drawtext` 需 ffmpeg 編進 freetype，不一定有 |
| 去背 | macOS Vision 人像分割（精準模式），邊緣要放大驗收 | 實測；跨平台可考慮其他去背模型，裝之前先查授權 |
| 蒙版調色（只調背景） | 去背遮罩＋背景調色後把人疊回去 | 實測 |
| 字放人物後面 | 去背層放在字卡之上（景深視差） | 實測 |
| 畫中畫、數字跳動、浮動標籤 | HTML 動畫元件 | 常見做法 |
| 2.5D 紙偶動畫 | 平面圖貼在細分網格上，用 Blender 做呼吸、歪頭、耳朵、眨眼，輸出透明 webm 疊回影片 | 實測；整隻手臂抬起、平面圖沒有的背面做不出來 |
| 角色動畫三層法 | ffmpeg 疊去背 PNG 做底片＋HTML 動畫做字卡特效＋獨立音效層 | 實測 |

## 三、HTML 動畫（字卡、特效層）

- **HyperFrames**：把 HTML 渲染成影片的開源工具，附一批現成的轉場、字卡、特效元件，可按「英文描述」搜尋。時間軸寫進 `window.__timelines`，要能被逐格 seek（不依賴即時播放）。**使用前確認版本與授權；不要執行會把自由文字外送的子指令。**
- **GSAP**：動畫函式庫。常用：`gsap.timeline()`、`to`／`from`／`fromTo`、`ease`、`stagger`。三個坑已寫在 SKILL.md 的「實作踩坑」（`set` 蓋掉 `from` 的起點、選擇器選到多個元素、變數撞名）。
- 動畫要寫成**時間的純函數**，同一時間點渲染兩次畫面才會一致（可重現檢查）。
- 逐格渲染時不要用 `"+=..."` 這類相對值定位，會被判錯。

## 四、音訊技法

| 技法 | 做法 | 狀態 |
|---|---|---|
| 響度標準化 | `loudnorm=I=-16:TP=-1.5`，後面接 `alimiter=level=disabled` | 實測 |
| 配樂接點 | `acrossfade` 或 `afade curve=qsin`，重疊約 0.6 秒（等功率交叉淡化） | 實測 |
| 講話時壓低配樂 | 固定一條平滑曲線（約 -11dB、前後 0.3 秒） | 實測；側鏈壓縮會忽大忽小，不建議 |
| 多軌混音 | 用 numpy 依時間碼疊進同長度的 wav，最後一次輸出 | 實測；ffmpeg 一次 `amix` 多個 `adelay` 可能截短 |
| 逐秒響度檢查 | `volumedetect`、`ebur128`，逐秒量 | 實測；整體正常不代表中間沒破洞 |
| 音效 | 用真實錄製的音效，每個對應一個畫面動作；從少開始 | 實測 |
| 去人聲保環境聲 | 音源分離（例如 demucs 的 two-stems）取不含人聲軌；關鍵音效段把人聲軌加回來並挖掉人聲頻段 | 實測 |
| 配音 | TTS 逐句生成，Python 依時間碼疊進 wav | 實測；使用者明說要才做 |

## 五、工具清單

### 本 skill 內附（`tools/`）
見 `tools/README.md`：機檢、切點接觸圖、分鏡板、截圖找出處、字卡地雷掃描、文字比對、交付、安全移垃圾桶。

### 需自行安裝（裝之前先查來源與授權，並問使用者）
| 工具 | 用途 | 狀態 |
|---|---|---|
| ffmpeg | 幾乎所有影音處理 | 必要 |
| 語音辨識（例如 Whisper 系列） | 逐字稿、字幕時間 | 實測；逐字時間是估的，要三層對齊 |
| demucs | 人聲／環境聲分離 | 實測 |
| PySceneDetect | 偵測鏡頭邊界 | 煙霧測試能跑，效果未用真素材驗 |
| Auto-Editor | 剪口播空白氣口 | 煙霧測試能跑；門檻要依素材試；請用官方發行版，不要用名稱相近的空殼套件 |
| librosa | 拍點、BPM | 煙霧測試能跑，只在要踩拍時用 |
| Blender（無頭模式） | 2.5D 紙偶、3D 道具 | 實測 |
| HyperFrames、GSAP | HTML 動畫字卡與特效 | 實測 |
| 瀏覽器自動化（例如 Playwright） | 錄網站／App 畫面（3 倍解析度） | 實測 |

### 已評估、先不裝的理由寫法（給你自己的 agent 參考）
裝工具前寫一行：用途、授權、來源、為什麼現有工具不夠。授權有傳染性（例如 GPL）或本機 ffmpeg 沒編進需要的濾鏡（例如影像穩定的 vidstab）的，先記下來，等素材真的卡到再說。
