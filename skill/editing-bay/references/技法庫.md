# 技法庫：畫中畫、蒙太奇與常用剪輯技法

何時讀：關卡 2 做技法選型、鏡頭表想「這裡可以怎麼處理」時。每項寫：用途、做法、注意。

狀態標示：
- **指令已跑過**：ffmpeg 指令用合成影片實際執行過，能出檔、規格正確。這代表指令沒寫錯，不代表用在真素材上好看，用真素材要再看一次。
- **畫面已驗**：用 HyperFrames 渲染範例並逐格看過畫面（範例原始碼在 `examples/`）。
- **實測**：做在成片上過。

指令裡 `a.mp4` 是主畫面、`b.mp4` 是第二畫面，尺寸以 1080×1920 直式為例，請依實際調整。

## 一、蒙太奇（Montage）

蒙太奇的共同規則：**每一鏡都要在段落裡新增意義**，不是把片段堆在一起。每鏡寫 `cut_reason`（見 `剪輯語法與敘事.md`）。

| 類型 | 用途 | 做法 | 注意 |
|---|---|---|---|
| 時間蒙太奇 | 成長、日子累積、時間流逝 | 同一主體、不同時間的畫面依序切；用年份、日期、數字滾動標出時間 | 每個時間點各自成組、不跳；真實素材的日期以使用者說的為準（實測） |
| 並置蒙太奇 | 兩件事放一起產生新意義 | A 鏡接 B 鏡，或分割畫面並排 | 效果有爭議，當可 A/B 的選項；紀實素材不可拼接不同時間的反應造假 |
| 對比蒙太奇 | 強調落差（前後、貧富、快慢） | 相反性質的畫面交替，景別與構圖刻意相近 | 對比要一眼看得懂，不靠字卡解釋 |
| 平行蒙太奇 | 兩條線同時進行、最後交會 | 兩線交替切，節奏越來越短，最後交會點切在動作上 | 先寫兩條線的時間表，避免觀眾搞不清誰是誰 |
| 節奏蒙太奇 | 預告片、廣告、卡拍點 | 依拍點切，由長鏡頭漸短（例如 1.5→0.8→0.4 秒），到高潮前停 0.3～0.75 秒 | 拍點可選，不為 BPM 縮短人物反應（見 `聲畫節奏與調色.md`） |
| 快閃蒙太奇 | 一次交代很多資訊或回憶 | 每鏡 0.13～0.8 秒，硬切為主，配音效重拍 | 每鏡仍要看得出主體；字卡別疊在快切上 |
| 製程蒙太奇 | 料理、組裝、施工 | 依真實製程順序，多個成品同步推進，成品只出現在最後的定裝段 | 見 SKILL.md「製程片的進度一致」（實測） |

## 二、畫中畫與多畫面

### 1. 畫中畫（Picture-in-Picture）
- **用途**：口播加畫面說明、手機錄屏加講者、看與被看的對照。
- **做法（指令已跑過）**：
```bash
ffmpeg -i a.mp4 -i b.mp4 -filter_complex \
  "[1]scale=360:-2[p];[0][p]overlay=W-w-40:H-h-300:enable='between(t,1,3)'" -an pip.mp4
```
  `enable='between(t,1,3)'` 讓小窗只在 1～3 秒出現。位置改 `overlay=x:y`。
- **加邊框／圓角**：小窗先 `pad` 加邊框；圓形小窗見下一項。進出場要有動態（淡入淡出或縮放），突然出現像貼圖。
- **注意**：小窗不要擋住主體的臉與字幕；避開平台底部與右側操作區；小窗裡的畫面也要有「正在發生的事」，不要放靜止畫面。

### 2. 圓形小窗
- **做法（指令已跑過）**：
```bash
ffmpeg -i a.mp4 -i b.mp4 -filter_complex \
  "[1]scale=400:400:force_original_aspect_ratio=increase,crop=400:400,format=yuva420p,\
geq=lum='p(X,Y)':cb='p(X,Y)':cr='p(X,Y)':a='if(lte(hypot(X-200,Y-200),200),255,0)'[p];\
[0][p]overlay=W-w-40:H-h-300" -an piprond.mp4
```
- **注意**：`geq` 較慢；圓形邊緣會有鋸齒，要放大看，必要時放大看邊緣。

### 3. 分割畫面（左右／上下）
- **用途**：同時呈現兩件事、前後對照、兩人對話。
- **做法（指令已跑過）**：
```bash
ffmpeg -i a.mp4 -i b.mp4 -filter_complex \
  "[0]scale=540:1920:force_original_aspect_ratio=increase,crop=540:1920[l];\
[1]scale=540:1920:force_original_aspect_ratio=increase,crop=540:1920[r];[l][r]hstack" -an split.mp4
```
  上下用 `vstack`，三格用 `hstack=inputs=3`。
- **注意**：每格先裁到同尺寸、同 fps；兩邊的聲音只留一邊，不要同時播；分隔線可用 `drawbox` 或 `pad` 加一條細線。

### 4. 前後對比拉桿
- **用途**：調色前後、修圖前後、產品改善。
- **簡單版（指令已跑過）**：`xfade=transition=wipeleft:duration=2:offset=1` 做一次擦除。
- **拉桿版**：用 HTML 動畫，在上層放「後」畫面，用 `clip-path: inset(0 X% 0 0)` 隨時間改變 X，再疊一根細白線當拉桿（**畫面已驗**，範例 `examples/motion-techniques/`）。拉桿速度要慢到看得清差異，約 1.5～2.5 秒走完。

## 三、時間處理

### 5. 定格（Freeze Frame）
- **用途**：強調一個瞬間、搭配字卡或轉場。
- **做法（指令已跑過）**：
```bash
ffmpeg -i a.mp4 -vf "trim=0:2,setpts=PTS-STARTPTS,tpad=stop_mode=clone:stop_duration=1" -an freeze.mp4
```
  最後一格再停 1 秒。
- **注意（實測）**：素材還在動時，下一格整張靜止會像卡住。先用二次減速緩停（來源最後約 0.6 秒的速度降到 0），再保持同一格；凍結做在影片裡，不疊 PNG（編碼不同會有微跳）。

### 6. 變速（Speed Ramp）
- **做法（指令已跑過，三段：原速→0.5 倍慢→原速）**：
```bash
ffmpeg -i a.mp4 -filter_complex \
 "[0:v]split=3[a][b][c];[a]trim=0:1,setpts=PTS-STARTPTS[v1];\
[b]trim=1:2,setpts=(PTS-STARTPTS)*2[v2];[c]trim=2:4,setpts=PTS-STARTPTS[v3];\
[v1][v2][v3]concat=n=3:v=1:a=0" -an ramp.mp4
```
  整段變速：畫面 `setpts=0.5*PTS`、聲音 `atempo=2.0`（單次 0.5～2.0；已跑過）。
- **注意（實測）**：變速鏡頭的聲音不要跟著拉伸，會有奇怪的變音，聲音與畫面分開取；慢動作只用 ≥60fps 的素材，或慢動作那鏡不推鏡，否則一頓一頓。

### 7. 倒放
- **做法（指令已跑過）**：`-vf "trim=0:2,setpts=PTS-STARTPTS,reverse"`。
- **注意**：`reverse` 會把整段載入記憶體，只用在幾秒的短片段；先 `trim` 再倒放。

### 8. Ken Burns（靜態圖慢慢推／移）
- **做法（指令已跑過，單張圖輸出 90 格）**：
```bash
ffmpeg -i p.png -vf "scale=2160:-2,\
zoompan=z='min(zoom+0.0015,1.3)':x='iw/2-(iw/zoom/2)':y='ih/2-(ih/zoom/2)':d=90:s=1080x1920:fps=30,format=yuv420p" kb.mp4
```
  輸入是**單張圖**（不要加 `-loop`，否則每格都會被展開 90 次）；先放大再 `zoompan` 可減少抖動。
- **注意**：照片臉不在中間時先算裁切位置；橫式照片放直式片先裁成直式保住臉，不用模糊填底（實測）。

### 9. 推近（Punch-in）與同機位跳接
- **用途**：同機位跳接時，後一段推近約 1.12 倍遮掉接縫；強調重點（實測）。
- **做法**：HTML 動畫對影片外層 wrapper 做 `scale`，不要動有時間屬性的媒體元素本身（**畫面已驗**，範例 `examples/transitions/`）；或 ffmpeg `crop` 加 `scale`。

## 四、包裝手法（口播、社群解說片常見）

| 手法 | 做法 | 狀態 |
|---|---|---|
| 蒙版調色（只調背景） | 人像分割出遮罩；背景單獨調色或降飽和，再把人疊回去 | 實測；邊緣要放大驗收手指、頭髮、肩膀。簡易版（只示範疊法，指令已跑過）：`[0]eq=saturation=0.2[g];[g][1]overlay` |
| 背景換影片牆 | 去背後把人疊在素材牆上 | 實測 |
| 超大字放人物後面 | 去背層放在字卡上方，做景深視差 | 實測；原片字幕壓在人身上會被當成「不是人」變透明，要補白或換無字幕素材 |
| 打字輸入框加進度條 | HTML 元件：輸入框逐字打出、進度條由左到右；時間由時間軸決定 | 畫面已驗（`examples/motion-techniques/`） |
| 關鍵詞浮動標籤 | 小標籤用實心底加深色粗字、放在空白處、有進場動態 | 實測 |
| 數字跳動 | HTML 動畫數字滾動 1.2～1.6 秒後停住，用等寬數字避免抖動 | 實測（見 `動態圖形與3D.md`） |
| 剪氣口 | Auto-Editor 依音量門檻剪空白；剪完字幕時間要從剪後版重做 | 功能已驗（合成素材，見 SKILL.md 輔助工具）；贅字不等於氣口，字幕不准比講的少字 |
| 閃白／暗角切 | 切點前後 2～3 格畫面變亮或變暗，讓這一刀看起來是故意的。ffmpeg：`eq=brightness=-0.4:enable='between(t,0.9,1.0)'`（暗角切），`brightness=0.6`（閃白） | 指令已跑過 |
| 底片顆粒與暗角 | `vignette=angle=PI/8`、`noise=alls=8:allf=t`（指令已跑過） | 實測 |

## 五、選技法的順序

1. 先問「這支片要觀眾感覺什麼」，再選技法；不是因為會做才用。
2. 每個技法說得出「用在哪一鏡、為什麼合」，給使用者的清單寫白話名稱加一句效果。
3. 沒做過的先做 5 秒測試，結果回填鏡頭表的技法欄；不行就換簡化備選。
4. 同一支片的技法要有節制：全片同一個 look，轉場 ≤3 種，每鏡一個主效果。
